# RM換算・MAX計算機

挙げた重さと回数から、MAX（1RM）と、何kgなら何回できるかを計算する Web ツールです。公開先は https://yuno-lab.com/rm-calc/ です。

- 重さと回数から、4つの式（Brzycki・Epley・Mayhew・Lombardi）でMAXを出す。計算には Brzycki の式を使う
- Brzycki の式を逆に使い、1〜10回が限界になる重さ（RM換算表）を2.5kg刻みで出す
- MAXの何%で何回できるかを、研究の表（Nuzzo 2024）から出す
- 重さ×回数の早見表と、MAXからの早見表（どちらも index.html に書いた静的な表）

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 入力フォーム・結果・早見表・注意・よくある質問・参考文献・免責 |
| `tests.html` | ロジックのテスト（ブラウザで開くと結果を表示） |
| `js/rm-calc.js` | 計算式、RM換算表、%の表、入力のチェック |
| `js/app.js` | フォーム・描画・保存・共有リンク |
| `css/style.css` | ほかのツールと共通（bench-program のものをコピー） |

計算式や表を変えたら `tests.html` を開き、テストがすべて通ることを確認してください。`index.html` の早見表は計算式から作った静的な表なので、式を変えたときは作り直します。
